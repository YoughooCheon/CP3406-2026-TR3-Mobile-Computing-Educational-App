# MemoryDesk

Flashcard-based learning app for university students (CP3406 Assessment 3).

## Screens
| Screen | What it shows |
|---|---|
| Welcome | Intro screen with a Get Started button |
| Home | Topic chips, cards due today, continue learning, daily goal |
| Learn | Featured Stanford Online lecture with thumbnail and YouTube links |
| Library | Search box that opens Google Scholar in the browser |
| Practice | Flip-card review with Again / Hard / Good / Easy |
| Stats | Streak, accuracy chart and topic mastery (sample data) |
| Settings | Reminder, break, text size, high contrast, reduce motion (not saved yet) |
| Privacy Center | What is stored and not collected (buttons not wired yet) |

## Open it
1. Android Studio: File > Open > select this folder and let Gradle sync (JDK 17).
2. Run on an emulator or device (minSdk 26).
